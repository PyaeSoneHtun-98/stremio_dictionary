# Subtitle Bridge v1.0.2

Subtitle Bridge v1.0.2 is the first Windows release containing the completed player UX refresh, while retaining the v1.0.1 runtime hotfix and the frozen production dictionaries.

## Player experience

- Visible centered buffering/loading feedback for Stremio and other HTTP/HTTPS streams.
- Buffering state distinguishes a real cache/seek stall from an intentional manual pause.
- Single-clicking the non-interactive video surface toggles play/pause.
- Double-clicking the video surface toggles fullscreen without also changing playback state.
- Surface gestures respect the Windows-configured double-click interval and ignore non-primary pointer buttons.
- Player controls, clickable subtitles, translation UI, panels, and visible top chrome are excluded from surface gestures.
- The main launcher is now a compact desktop-app interface with clear Local video and Stremio actions plus current-session status.

## External subtitles

- Native **Choose subtitle file** support for SRT, ASS, and SSA.
- Existing drag-and-drop external subtitle loading remains available.
- Picker cancellation is silent.
- Subtitle picker requests are bound to the media session that opened them, preventing a subtitle selected from an old dialog from being attached to a newly opened video.

## Dictionary and phrase lookup

v1.0.2 includes the existing frozen production language data:

- 30,000-headword English → Burmese Dictionary v1.0;
- 3,000 canonical Phrase Dictionary v1.0.0 entries;
- 4,827 stored phrase forms;
- 7,827 collision-free phrase lookup keys;
- longest-match phrase lookup with normal single-word fallback.

Normal dictionary and phrase lookup remain offline.

## Runtime and installer reliability

v1.0.2 retains the v1.0.1 runtime fix:

- mpv is pinned to the immutable first-party stable v0.41.0 x86_64 Windows MSVC archive;
- the mpv archive is SHA-256 verified before installation;
- FFmpeg remains pinned and hash verified;
- CI performs live public runtime download, digest, extraction, and executable-launch verification;
- setup preserves rollback-safe upgrade and interrupted-upgrade recovery behavior;
- runtime/setup failures surface useful details instead of being reported only as an internet-connection problem.

## Recommended download

**`SubtitleBridge-Setup-x64.exe`**

Double-click the installer on Windows 10/11 x64. The setup executable installs Subtitle Bridge for the current user and provisions pinned app-local mpv/FFmpeg runtimes automatically.

Existing Subtitle Bridge installations can be upgraded by running the v1.0.2 setup executable; uninstalling first is not required.

## Verification

The release is published only after:

- exact-head pull-request CI passes;
- a real Windows install/upgrade and representative playback smoke test passes;
- final Codex review reports no remaining P1/P2/P3 findings;
- the merged exact `master` SHA passes push CI;
- the release workflow rebuilds and revalidates that same successful `master` SHA;
- generated installer/ZIP checksum files are verified before publication.

## Known limitations

- Windows x64 only.
- The installer is not code-signed, so Windows SmartScreen may show an **Unknown Publisher** warning.
- Image-based subtitle tracks such as PGS/VobSub are not converted into clickable text.
- Rich ASS/SSA styling is simplified into readable interactive dialogue.
- Stremio updates may require re-enabling the opt-in compatibility integration.
- macOS and Linux installers are not included.
- Automatic application updates are not yet implemented.
