# Subtitle Bridge v1.0.3

Subtitle Bridge v1.0.3 is the first public Windows release containing secure, user-approved in-app update support.

It retains the stable player UX, frozen word/phrase dictionaries, Stremio handoff, rollback-safe installer, and immutable runtime fixes from v1.0.2.

## Secure in-app updates

Subtitle Bridge can now check the official stable GitHub Release shortly after startup and periodically while the app is running.

When a newer stable version exists:

- the launcher shows the newer version and release notes;
- **Download update** downloads the normal Windows setup EXE and its published SHA-256 file;
- all network, filesystem, hashing, and process-launch work remains in the Electron main process;
- the installer SHA-256 is verified after download;
- the installer is hashed again immediately before launch;
- **Install and restart** is always an explicit user action;
- installation is blocked while media is loading, playing, or paused;
- offline/update-server failures are non-fatal and retryable.

The updater trusts only stable releases from the fixed official repository:

`PyaeSoneHtun-98/stremio_dictionary`

It requires the exact assets:

- `SubtitleBridge-Setup-x64.exe`
- `SubtitleBridge-Setup-x64.exe.sha256`

Draft, prerelease, malformed, noncanonical, older, and equal-version releases are ignored or rejected safely.

## Custom install directories

In-app updates preserve a non-default installation directory.

The updater derives the current installation directory from the running Subtitle Bridge executable and passes that directory to the existing setup bootstrap through `SUBTITLE_BRIDGE_INSTALL_DIR`.

This prevents an in-app update from creating a second copy in the default per-user install location.

## First-updater bootstrap

The public v1.0.2 release predates the updater.

Existing public v1.0.2 users therefore need to install v1.0.3 manually once.

After v1.0.3 is installed, future public releases can be discovered, downloaded, verified, and started from inside Subtitle Bridge.

## Player and subtitle experience

v1.0.3 retains the v1.0.2 player improvements:

- centered buffering/loading feedback for HTTP/HTTPS and Stremio streams;
- manual-pause-safe buffering semantics;
- single-click video-surface play/pause;
- Windows-system-aware double-click fullscreen;
- native external SRT/ASS/SSA picker plus drag-and-drop loading;
- compact launcher and current-session summary;
- subtitle delay, size, and position controls.

## Dictionary and phrase lookup

The frozen production language data remains unchanged:

- 30,000-headword English → Burmese Dictionary v1.0;
- 3,000 canonical Phrase Dictionary v1.0.0 entries;
- 4,827 stored phrase forms;
- 7,827 collision-free phrase lookup keys;
- longest-match phrase lookup with normal single-word fallback.

Normal word and phrase lookup remains offline.

## Runtime and installer reliability

v1.0.3 retains the stable installer/runtime behavior from v1.0.1/v1.0.2:

- immutable first-party stable mpv v0.41.0 x86_64 MSVC archive;
- pinned/hash-verified FFmpeg runtime;
- live public runtime verification in CI;
- app-local managed runtimes;
- rollback-safe upgrades;
- interrupted-upgrade recovery;
- custom install-directory support;
- fail-closed ownership checks;
- reversible Stremio integration cleanup.

## Recommended download

**`SubtitleBridge-Setup-x64.exe`**

Existing Subtitle Bridge installations can be upgraded directly by running the v1.0.3 setup executable; uninstalling first is not required.

## Release verification

The release is published only after:

- exact-head pull-request CI passes;
- real Windows v1.0.2 → v1.0.3 manual upgrade smoke testing passes;
- final Codex review reports no remaining P1/P2/P3 findings;
- the merged exact `master` SHA passes push CI;
- Release Windows rebuilds and revalidates that same successful source SHA;
- installer/ZIP checksum files are verified before publication.

After publication, an updater-enabled v1.0.2 feature build is used for the first real official end-to-end in-app update test to v1.0.3.

## Known limitations

- Windows x64 only.
- The installer is not code-signed, so Windows SmartScreen may show an **Unknown Publisher** warning.
- Public v1.0.2 does not contain the updater and must move to v1.0.3 manually.
- Image-based subtitle tracks such as PGS/VobSub are not converted into clickable text.
- Rich ASS/SSA styling is simplified into readable interactive dialogue.
- Stremio updates may require re-enabling the opt-in compatibility integration.
- macOS and Linux installers are not included.
