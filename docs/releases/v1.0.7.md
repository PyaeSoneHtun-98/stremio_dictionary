# Subtitle Bridge v1.0.7

Subtitle Bridge v1.0.7 improves the Windows player controls, offline dictionary, stream launcher and app branding.

## What's new

- Open an HTTP or HTTPS media URL directly from the main window using **Open stream** or Enter, including Stremio's local streams. This accepts media URLs, not arbitrary video website pages.
- Switch between available audio tracks while playback continues. The consolidated CC/Tracks panel also contains subtitle selection, external subtitle loading, delay, size and vertical-position controls.
- Use the new neutral charcoal theme with white/gray controls and the approved Subtitle Bridge logo across the launcher, player windows, Windows app and setup icons.
- Look up **40,011 unique headwords** and **4,000 canonical phrases** offline. The frozen base dictionaries are preserved; pinned extensions add vocabulary, phrase forms and targeted common-word corrections. Longest-match phrase lookup supports hyphenated subtitle tokens.
- Report a missing or questionable dictionary entry using the small flag at the bottom right of the translation card. Reports are sent only when clicked; normal dictionary lookup stays offline. Reports exclude subtitle context, media paths, stream URLs and credentials.

## Playback and subtitle improvements

- Interactive subtitles move down when player controls hide and move back up when controls return, preserving the saved vertical offset.
- Missing, unsupported and failed-subtitle notices dismiss after four seconds. Active subtitle loading remains visible.
- Subtitle dropdown options remain reachable in short windows. Size/position controls prevent overlapping preference writes.
- **Pause automatically when I click a word** is enabled by default for fresh settings; an existing saved preference is preserved.
- Translation in this release is constrained to **Offline dictionary → Burmese**, including legacy settings. Google Translate is hidden pending live acceptance; dormant backend support does not enable it in this release.

## Installer and updater

- Retain the v1.0.6 updater working-directory lock fix and add physical-path containment checks, including Windows junction regression coverage.
- Replace the expired FFmpeg daily-download pin with a hash-verified September 2026 month-end LGPL shared build. Existing old setup files retain their original manifests; use this release's setup for a new install.
- Preserve custom install locations, transactional rollback, interrupted-upgrade recovery and process-identity protections.

## Recommended download

**`SubtitleBridge-Setup-x64.exe`**

Setup provisions the pinned, SHA-256-verified mpv and FFmpeg dependencies. The portable ZIP does not bundle those media runtime binaries.

## Known limitations

- Windows x64 only. The installer is not code-signed; Windows may show an **Unknown Publisher** warning.
- Image subtitles such as PGS/VobSub are not clickable text. Rich ASS/SSA styling is simplified.
- Media URL support depends on mpv and the stream's codec, authentication and subtitle tracks. This is not a browser or website extractor.
- The optional, reversible Stremio compatibility integration may need re-enabling after a Stremio update.
- Dictionary coverage and translations are not exhaustive; missing or questionable entries can be reported for manual review.
- Reporting requires access to the public HTTPS endpoint and has no persistent offline queue.
