# Subtitle Bridge v1.0.4

Subtitle Bridge v1.0.4 is a focused Windows updater reliability release.

It publishes the shutdown-race fix from Issue #52 / PR #54 while keeping the v1.0.3 player, subtitle, dictionary, Stremio, runtime, and updater trust behavior unchanged.

## Updater shutdown-race fix

On one Windows PC, the v1.0.3 in-app updater successfully downloaded and verified the release installer but setup failed while replacing the existing installation because the install directory was still in use.

v1.0.4 fixes that handoff defensively.

The updater now passes a verified parent-process identity to setup using:

- process ID;
- executable path;
- process start time.

Setup verifies that identity before waiting, so a recycled PID belonging to an unrelated process is not treated as the updater parent.

## Older-updater compatibility

The fixed installer does not require the launching updater to provide the new identity metadata.

Older updater-enabled builds can still launch the v1.0.4 setup. Setup gives an already-running installed Subtitle Bridge process a bounded grace period to finish shutting down before the install-directory swap.

This is important for updating from builds that were created before the new parent-identity handoff existed.

## Safer Windows process detection

When Windows process metadata does not expose `ExecutablePath`, setup uses a PID-specific fallback instead of silently skipping the process.

The fallback includes:

- `PROCESS_QUERY_LIMITED_INFORMATION`;
- `QueryFullProcessImageName`;
- SID-based owner comparison through `GetOwnerSid`.

An inaccessible process owned by another Windows user can only be ignored for the exact standard per-user target:

`<LocalApplicationData>\Programs\Subtitle Bridge\Subtitle Bridge.exe`

Custom/shared install locations remain fail-closed.

Before granting that narrow cross-user exemption, setup checks the executable and every ancestor up to the volume root for reparse points such as junctions, symlinks, and mount points. A redirected path disables the exemption.

## Transient file-lock handling

The existing-install directory swap now uses bounded retries around same-volume `System.IO.Directory.Move`.

This avoids the partial recursive-destination behavior that can occur when retrying PowerShell `Move-Item` after a lock failure.

Retries only continue while the transaction invariants remain safe:

- the source directory still exists;
- the backup destination is still absent;
- the retry limit has not been reached.

Rollback and interrupted-upgrade recovery remain unchanged.

## Security and behavior preserved

v1.0.4 does not weaken the updater trust policy.

The updater still:

- checks only the fixed official GitHub repository;
- requires canonical stable `vX.Y.Z` releases;
- rejects draft, prerelease, malformed, equal, and older versions;
- requires the exact Windows setup and checksum assets;
- restricts downloads to approved HTTPS GitHub hosts;
- verifies SHA-256 after download and again immediately before installation;
- requires explicit user approval to install;
- blocks installation while playback is active;
- preserves custom install directories;
- keeps renderer Node integration disabled and context isolation enabled.

The stable playback, subtitle, dictionary, phrase, runtime, and Stremio behavior from v1.0.3 is unchanged.

## Recommended download

**`SubtitleBridge-Setup-x64.exe`**

Existing v1.0.3 installations can update through the in-app updater after v1.0.4 is published.

An updater-enabled older feature build can also consume the fixed installer because the installer preserves the no-parent-identity compatibility path.

## Release verification

The updater-race implementation was reviewed on PR #54 with no remaining P1/P2/P3/P4 findings.

Its exact reviewed head passed Windows CI coverage for:

- recycled PID handling;
- missing CIM executable paths;
- limited-access process queries;
- SID-based cross-user isolation;
- custom/shared path fail-closed behavior;
- junction/reparse-point handling, including ancestors above LocalApplicationData;
- old updater compatibility;
- verified updater-parent shutdown;
- transient install-directory file locks;
- packaged install/upgrade/runtime/Stremio regressions.

The v1.0.4 release is published only after the release-only version/documentation PR also passes exact-head CI and final review, followed by successful exact-master CI and Release Windows verification.

## Post-publication acceptance

Issue #52 remains open until the real affected/test Windows PC successfully completes the official in-app update to v1.0.4 without manually closing Subtitle Bridge.

## Known limitations

- Windows x64 only.
- The installer is not code-signed, so Windows SmartScreen may show an **Unknown Publisher** warning.
- Image-based subtitle tracks such as PGS/VobSub are not converted into clickable text.
- Rich ASS/SSA styling is simplified into readable interactive dialogue.
- Stremio updates may require re-enabling the opt-in compatibility integration.
- macOS and Linux installers are not included.
