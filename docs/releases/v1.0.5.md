# Subtitle Bridge v1.0.5

Subtitle Bridge v1.0.5 is a Windows feature and reliability release built on top of v1.0.4.

It adds local MP4 playback, faster subtitle synchronization controls, launcher/player polish, and safer Stremio integration state handling while preserving the hardened updater and installer behavior from v1.0.4.

## Local MP4 playback

Subtitle Bridge can now open local MP4 files through the same mpv playback path used for MKV.

MP4 playback does not require an embedded subtitle track. During playback, users can load external text subtitles through the existing controls:

- SRT;
- ASS;
- SSA;
- drag and drop.

Clickable subtitle words, Burmese dictionary lookup, phrase lookup, subtitle styling controls, and normal playback controls remain available.

## Faster subtitle synchronization

The player now supports keyboard timing shortcuts:

- **G** — move subtitles 0.1 seconds earlier;
- **H** — move subtitles 0.1 seconds later.

The shortcut uses the same authoritative subtitle-delay state as the existing subtitle tools, so keyboard and UI adjustments remain synchronized.

A temporary on-screen indicator shows the resulting delay. The supported delay range is -20.0 to +20.0 seconds.

## Launcher and player polish

v1.0.5 includes release polish for the main launcher and playback lifecycle:

- a more compact idle launcher;
- unnecessary idle diagnostics are hidden;
- normal player-window close returns the launcher to idle without exposing raw mpv/IPC errors;
- genuine playback-open failures use concise user-facing recovery messaging;
- rapid reopen/close paths include additional mpv IPC cleanup and stale-input protection.

## Safer Stremio integration state

The launcher now reports the detected Stremio handoff state instead of treating enable/disable actions as blind mutations.

The integration distinguishes clean enabled/disabled states from repair or unknown states.

Recovery behavior is fail-closed:

- recorded targets that disappear or lose their patch require a reset;
- a verified target cannot hide another stale recorded target;
- edited or malformed generated marker blocks are not automatically replaced or removed;
- Disable may remove the exact generated Subtitle Bridge block even if Stremio changed surrounding layout;
- cleanup preserves surrounding Stremio content;
- development mode is inspection-only and does not compare against Electron as if it were an installed Subtitle Bridge executable.

## Preserved updater and installer protections

v1.0.5 keeps the v1.0.4 updater shutdown-race protections and security model, including:

- official-repository-only update checks;
- canonical stable version/tag validation;
- SHA-256 verification after download and immediately before installation;
- explicit user approval before install;
- playback-active installation blocking;
- custom install-directory preservation;
- verified updater-parent identity;
- recycled-PID protection;
- bounded transient install-directory lock handling;
- rollback-safe setup behavior;
- renderer Node integration disabled with context isolation enabled.

## Known limitations

- Windows x64 only.
- The installer is not code-signed, so Windows SmartScreen may show an **Unknown Publisher** warning.
- Image-based subtitle tracks such as PGS/VobSub are not converted into clickable text.
- Rich ASS/SSA styling is simplified into readable interactive dialogue.
- Stremio updates can change its local layout and may require resetting/re-enabling the opt-in compatibility integration.
- macOS and Linux installers are not included.
