# Subtitle Bridge v1.0.1

Subtitle Bridge v1.0.1 is a Windows installer hotfix release.

## Important installer fix

The v1.0.0 setup executable itself is intact and matches its published SHA-256, but its runtime manifest pinned mpv to an upstream rotating development-build release. That specific mpv asset was later removed by upstream, causing fresh v1.0.0 installs to fail while downloading the managed mpv runtime.

v1.0.1 fixes that by pinning mpv to the immutable first-party **mpv v0.41.0 stable** x86_64 Windows ZIP and verifying the archive with the upstream-published SHA-256 before installation.

The installer now also reports a more useful runtime/setup failure detail instead of always suggesting that the user's internet connection is the problem.

## Also included

This hotfix is built from current stable master, so it also includes the production Phrase Dictionary v1 integration:

- 3,000 canonical English multi-word phrases;
- 4,827 stored forms;
- 7,827 collision-free lookup keys;
- longest-match phrase detection with normal single-word fallback;
- the unchanged frozen 30,000-headword Dictionary v1.

## Recommended download

**`SubtitleBridge-Setup-x64.exe`**

Double-click the installer on Windows 10/11 x64. The installer provisions pinned, SHA-256-verified app-local mpv and FFmpeg runtimes automatically.

## Verification

The release is published only after exact-source CI passes validation, Windows packaging, packaged install/upgrade/runtime/Stremio acceptance, and release checksum verification.

The setup EXE and portable ZIP are accompanied by SHA-256 checksum files.

## Known limitations

- Windows x64 only.
- The installer is not code-signed, so Windows SmartScreen may show an **Unknown Publisher** warning.
- Image-based subtitle tracks are not converted into clickable text.
- Stremio updates may require re-enabling the opt-in compatibility integration.
- macOS and Linux installers are not included.
