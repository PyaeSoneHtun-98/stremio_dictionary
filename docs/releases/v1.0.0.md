# Subtitle Bridge v1.0.0

Subtitle Bridge v1.0.0 is the first stable Windows release.

## Recommended download

**`SubtitleBridge-Setup-x64.exe`**

Double-click the installer on Windows 10/11 x64. No Git, Node.js, npm, terminal commands, PATH editing, or separate mpv/FFmpeg setup is required.

The installer downloads pinned mpv and FFmpeg runtime archives from the sources recorded by the project and verifies their SHA-256 hashes before installing them app-locally.

A matching **`SubtitleBridge-Setup-x64.exe.sha256`** file is attached to this release.

## Highlights

- Local MKV playback.
- Supported HTTP/HTTPS and Stremio stream playback.
- Clickable synchronized English text subtitles.
- Drag-and-drop external SRT/ASS/SSA subtitles.
- Burmese lookup from the frozen 30,000-headword Dictionary v1.0.
- Offline dictionary lookup with no account or API key required.
- Subtitle delay, size, and position controls.
- One-click current-user Windows installation.
- Start Menu integration and Windows Installed Apps uninstall support.
- Pinned, hash-verified installer-managed mpv/FFmpeg.
- Rollback-safe upgrades, interrupted-upgrade recovery, committed-transaction cleanup, and concurrent-setup protection.
- Opt-in/reversible Stremio **Play in Subtitle Bridge** integration.
- Fail-closed and exhaustive Stremio cleanup.
- Redacted rotating diagnostics.
- Electron Node integration disabled and context isolation enabled.

## Release files

The setup EXE is the recommended normal-user download.

## Known limitations

- Windows x64 only.
- The current installer is not code-signed, so Windows SmartScreen may show an **Unknown Publisher** warning.
- Interactive subtitle support targets text subtitle formats; image-based subtitle tracks are not converted into clickable text.
- Stremio updates can change its local external-player layout and may require re-enabling the integration.
- macOS and Linux installers are not included in v1.0.0.

## Verification

The release is published only after the repository's Windows CI succeeds on the exact `master` commit used for the release. The installer and portable ZIP are accompanied by SHA-256 checksum files.
