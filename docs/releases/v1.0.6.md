# Subtitle Bridge v1.0.6

Subtitle Bridge v1.0.6 is a focused Windows updater hotfix.

It fixes the real in-app upgrade failure reproduced after v1.0.5 publication:

`Exception calling "Move" ... The process cannot access the file because it is being used by another process`

The failure occurred during the install-directory swap after the updater had already downloaded and verified the release successfully.

## Root cause

The downloaded setup executable could inherit Subtitle Bridge's installed application directory as its current working directory.

The setup bootstrap then launched PowerShell without explicitly changing that working directory.

That meant setup itself could keep the old installation directory in use while the installer attempted to rename it to the transaction backup directory.

## Fix

v1.0.6 isolates installer working directories from the installed application tree:

- the in-app updater launches the downloaded setup executable with the download directory as its explicit working directory;
- updater launch rejects a setup working directory that is inside the current install directory;
- SetupBootstrap immediately changes its own current directory to its temporary extraction root;
- the PowerShell installer is launched with the extracted package directory as its working directory;
- before temporary setup files are deleted, the bootstrap changes its current directory back to the system temporary directory.

## Regression coverage

Windows CI now performs a packaged upgrade where the setup executable is deliberately launched with the installed Subtitle Bridge directory as its working directory.

The upgrade must succeed and the setup status log must confirm that the bootstrap relocated its working directory before the directory swap.

PR #61 exact-head CI #501 passed this regression. Merged master CI #502 also passed.

## Existing protections preserved

This hotfix does not change the updater trust or security model.

The updater still:

- checks only the official GitHub repository;
- accepts only canonical stable release versions;
- verifies the setup SHA-256 after download and again before installation;
- requires explicit user approval;
- blocks installation while playback is active;
- preserves custom installation directories;
- verifies updater-parent process identity;
- protects against recycled PIDs;
- retains bounded transient-lock retries;
- preserves transactional rollback and interrupted-upgrade recovery;
- keeps renderer Node integration disabled and context isolation enabled.

Playback, local MKV/MP4 support, subtitles, dictionary/phrase lookup, Stremio integration, and v1.0.5 UI behavior are unchanged.

## Recommended download

**`SubtitleBridge-Setup-x64.exe`**

For the affected machine, the important acceptance test is the normal **in-app update from v1.0.5 to v1.0.6**.

## Known limitations

- Windows x64 only.
- The installer is not code-signed, so Windows SmartScreen may show an **Unknown Publisher** warning.
- Image-based subtitles such as PGS/VobSub are not converted into clickable text.
- Rich ASS/SSA styling is simplified.
- Stremio updates may require resetting/re-enabling the optional compatibility integration.
- macOS and Linux installers are not included.
